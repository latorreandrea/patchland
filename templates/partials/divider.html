{% comment %} Multi-layer animated wave divider between sections. - `fill` is a Tailwind fill utility matching the destination section colour (e.g. fill-forest-900, fill-brass-500, fill-parchment-200/70). - `flip` (any non-empty value) draws the crest downward, for the bottom edge of a section. Three layers of the same wave scroll horizontally at different speeds (parallax/depth) with different heights: - background (opacity 30%, slowest): tallest wave - middle (opacity 60%, medium, reversed): medium wave - foreground (opacity 100%, fastest): shortest wave Each layer is an HTML wrapper (w-[200%]) animated with translateX(-50%): the wave pattern repeats every half of the wrapper, so the loop is always seamless and never leaves gaps.
