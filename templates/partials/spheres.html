{% comment %} Decorative background spheres with a scroll-driven horizontal entrance/exit (parallax) animation, powered by Alpine.js + CSS transforms. HOW TO USE ---------- Include this partial as the first element inside a `relative`
. The section MUST carry the Alpine wiring — the `direction` argument decides the motion:
x-ref="stage" @scroll.window.passive="onScroll" @resize.window="onResize" class="relative ..."> {% include 'partials/spheres.html' %} ...
Motion contract (a pure function of scroll position, fully reversible): - 'left-to-right' → spheres enter from -X, reach translateX(0) when the section is centred in the viewport, then exit toward +X. - 'right-to-left' → the exact mirror image. The `scrollSpheres` Alpine component is registered once per page (see the `postloadjs` block in home/templates/home/index.html). Two sphere distributions are available for variety: - default (no `variant`) → distribution A - `variant='b'` → distribution B PERFORMANCE ----------- The scroll translateX lives on an OUTER span (`will-change-transform`, compositor-only). The idle `drift` animation (float + scale) runs on an INNER span. The two transforms MUST stay on separate elements: a CSS keyframe animation overrides the inline transform on the same element. ACCESSIBILITY ------------- `motion-reduce:animate-none` on the inner spans, plus the component's `prefers-reduced-motion` check, keep the spheres static at their base position for users who prefer reduced motion. {% endcomment %}
